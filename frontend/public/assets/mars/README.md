# MARS 2.0 Visual Assets

Place the supplied institutional images in this directory using these filenames so the home dashboard automatically uses them:

- `indian_railways_emblem.png` — Indian Railways emblem/crest used in the header
- `indian_railways_logo.png` — full Indian Railways wordmark/logo
- `vande_bharat_hero.jpg` — main Vande Bharat / railway corridor hero image
- `viksit_bharat_railways.png` — Viksit Bharat / Railways brush-stroke graphic
- `indian_flag.png` — optional Indian tricolour accent
- `mars_train_icon.png` — optional MARS train mark for compact branding

The UI has graceful fallbacks, so the dashboard remains usable before the images are added.
